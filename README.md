# Vyson BodyFit

Parametric 3D mannequin (female/male) built from body measurements, with a digital showcase and AI fit labels (✅ ideal / ⚠️ tight / ❌ doesn't fit).

- 360° rotation, project-style dimension lines ("cotas"), layers
- Smiling face, hands with fingers, makeup (lipstick, eyeshadow, blush), earrings, bracelet, ring, heels
- No face photos, avatar only. 18+. Optional clothed photo for the OpenCV 5 digital tape, never stored.

Open `index.html` (three.js 0.160, local).

## 3D body
Base mesh and gender targets from [MakeHuman](https://github.com/makehumancommunity/makehuman) (CC0). `corpo_f.json` / `corpo_m.json` are generated by `tools/gera.py`; the page deforms the mesh by bust, waist, hip, shoulder, inseam and height.
